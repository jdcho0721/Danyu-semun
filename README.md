# 다뉴세문경, 빛의 연대기
### Danyusemun-gyeong — Chronicle of Light

국보 제141호 **다뉴세문경(多鈕細文鏡)** 뒷면의 삼각형 빗금 무늬를, 반도체 회로를 설계하던 눈으로 다시 읽은 연구를 바탕으로 만든 게임입니다.
퍼즐(간섭의 규칙), 빛 실험(빛을 돌리다), 문답(장인의 문답), 전투(거울의 전사들)를 거치며 거울의 빛을 다루는 법을 익힙니다.
